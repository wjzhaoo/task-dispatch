# .taskignore 快照排除与最近连接耗时分析

## 范围

- 根目录 `.taskignore` 用于排除快照中的大文件或生成目录，并影响后续差异扫描。
- 每次任务尝试固定忽略规则；`.taskignore` 本身进入快照，规则变更可被检测。
- 与现有 `snapshot.exclude`、批次快照、审核副本及旧快照兼容。
- 从最近试跑的服务事件量化连接、等待、开始工作、首个任务和首次派发的耗时。

## 验证

- 新增针对大文件、通配符、反选、规则冻结及任务路径的测试。
- 执行 Node 全量测试和语法检查。

## 风险

- 被忽略内容不参与备份与差异检查，因此必须清楚说明适用边界；规则文件变更会作为工作区变更出现。

## 结果

- `.taskignore`、策略冻结、旧尝试兼容、派发边界检查已实现并验证。
- 最近连接的额外代码原因是 Codex 当前日志带后缀 UUID，旧定位器误选旧日志；已修复并新增回归测试。
