# Web 任务看板重设计

用户要求：标记需要大脑审核的任务，展示依赖或并行关系，并始终知道完整任务总数。

- 重设计统一 Web 控制台任务页，保留现有操作和详情。总任务、已验收、待大脑终审、异常及整体进度独立于筛选。
- 阶段概览展示累计任务和本轮修复范围、整体终审状态；原任务在补修轮继续归属同一终审范围。
- 默认展示全部任务的依赖分层图，前置连线、节点选择与关联高亮；可切换列表、搜索、阶段和状态筛选。图中筛选保留上下文，列表显示匹配项。
- 无依赖任务同层排列，明确是可并行规划、当前项目串行执行，不改变调度机制。缺失依赖和循环明确报错，不制造错误关系。
- 提取纯数据计算和可复用展示模块；测试计数、补修累计范围、依赖分层、异常图、筛选及浏览器交互。隔离预览不重启真实服务，临时文件限本项目 tmp。

完成：上述界面和数据展示已实现，18 项相关测试及真实浏览器检查通过，详见 [实施记录](../summaries/2026-09-26-Web任务看板重设计.md)。
