# 任务总结 — 空系统管理入口

- **任务类型**：修复
- **任务分级**：标准档
- **关联文档**：`docs/specs/系统项目目录清单与Web管理端.md`

## 1. 任务内容

修复没有任何项目时 `dashboard.bat` 和 `web-console.bat` 无法启动的问题。CLI 增加空目录刷新模式；Web 增加独立的内存态项目目录主页，支持空状态、周期刷新项目与任务计数，以及跳转到项目自己的管理台。

## 2. 方案与选择

- **候选方案**：创建用户级空调度服务；无状态系统目录管理入口（推荐且由用户选择）。
- **选择理由**：无状态入口不产生第二类全局实例，系统缓存仍只有项目目录清单，项目任务和凭据继续严格保存在工作目录。

## 3. 根因分析

上一版虽然建立了项目目录清单，但 CLI/Web 启动器仍先调用项目服务根目录解析；清单为空时在页面和菜单创建之前就抛错。项目管理页的实时刷新无法解决入口进程不存在的问题。

- Web 目录主页由 `web-console.bat` 窗口承载；关闭该窗口会停止目录主页，但不会停止任何项目调度服务。
