# 任务总结 — 总目录清单与 Web 管理端

- **任务类型**：修复 + 需求
- **任务分级**：标准档
- **关联文档**：`docs/specs/系统项目目录清单与Web管理端.md`

## 1. 任务内容

将系统缓存索引升级为包含全部项目工作目录和项目内数据目录的总目录清单；命令行与 Web 管理入口不再要求用户提供 `--workspace`。Web 汇总页支持显示失效项目，并可打开其他项目自己的可操作管理台。迁移工具从旧服务状态自动确定工作目录。

## 2. 方案与选择

- **候选方案**：继续用参数选择项目；或以系统项目目录清单作为正常发现入口（推荐并由用户确认）。
- **选择理由**：工作目录已经是可持久化的项目元数据，重复要求用户输入会造成错误选择，也无法形成真正统一的 Web 管理入口。

## 3. 根因分析

旧实现的系统索引以服务目录为主，只把工作目录附在 `workspaces` 数组中。管理台发现多个服务时没有项目级选择能力，于是回退为要求 `--workspace`；迁移工具同样重复要求该参数。Web 页面虽能汇总其他服务状态，但启动器无法在多项目时无参数进入，外部项目也只能只读查看。
