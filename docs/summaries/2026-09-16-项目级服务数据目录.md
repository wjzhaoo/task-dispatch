# 任务总结 — 项目级服务数据目录

- **任务类型**：需求
- **任务分级**：标准档
- **关联文档**：`docs/specs/项目级服务数据目录.md`

## 1. 任务内容

将桌面项目的默认服务数据从用户目录下的全局 `.task-dispatch-service` 改为工作区旁挂的项目独立目录。新增统一数据根解析器，接入桌面客户端、看板/清理入口、安装链接及 Qoder 兼容路径，并补充测试与用户文档。

默认解析优先级为：显式 `--data`、已有凭据 `data`、工作区旁挂目录、旧全局默认目录。既有全局数据不会被自动读取、迁移或删除。

## 2. 方案与选择

- **候选方案**：项目旁挂目录（采用、推荐）；项目内部隐藏目录；仅增加管理台彻底删除；自动拆分迁移旧全局目录。
- **选择理由**：旁挂目录实现物理隔离和按项目删除，同时保持服务数据与源码工作区不重叠，不需要放宽快照、Git、凭据及允许路径安全边界。
