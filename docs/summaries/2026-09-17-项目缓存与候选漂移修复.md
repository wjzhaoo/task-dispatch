# 任务总结 — 项目缓存与候选漂移修复

- **任务类型**：修复
- **任务分级**：标准档
- **关联文档**：`docs/specs/项目内缓存改绑与候选漂移治理.md`

## 1. 任务内容

将新项目的状态、快照、收据、审核副本和凭据统一放入项目内 `.task-dispatch/runtime/<project-key>/`；系统缓存仅保存项目目录索引；阻止无 workspace 时创建空公共服务；增加旧目录安全迁移工具；修复计划文件更新导致候选误过期。

## 2. 方案与选择

- **候选方案**：系统安全凭据库 + 项目内重缓存；严格项目内全部数据；继续旁挂目录。
- **最终选择**：严格项目内全部数据。
- **选择理由**：用户要求项目状态与凭据均随项目目录隔离，系统目录只承担目录表。

## 3. 根因分析

- `projectDataRoot()` 原先明确返回工作区父目录的旁挂目录。
- 管理入口缺少 workspace 时回落并启动用户级旧服务，造成一个空的第二实例。
- 审核前后按完整 workspace manifest 比较，未区分大脑维护的 `.task-dispatch/plan.md` 与业务候选；最近试跑 T03 的唯一差异正是该计划文件。
