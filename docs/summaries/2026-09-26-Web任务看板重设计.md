# Web 任务看板重设计

已更新统一 Web 控制台，默认展示完整任务依赖图，支持任务列表切换和搜索、阶段、状态筛选。

- 总数、已验收、待大脑终审、异常及整体完成进度始终按完整计划计算。
- 大脑审核标记出现在每个任务卡片上；阶段概览和任务详情展示补修轮累计审核范围、最新状态和历轮结论。
- 依赖分层、分叉汇合连线和关联高亮展示前后关系；同层表示无前后依赖，可并行规划，实际调度仍串行。
- 循环依赖、缺失依赖及受影响任务单独提示；筛选和图内滚动位置在页面快照刷新时保留。
- 保留任务处置按钮、尝试时间线和深色主题；模块通过新增的静态资源路由加载。

## 验证

相关 18 项自动化测试通过：6 项数据模型测试，管理台和网关回归、模块资源路由、阶段补修完整流程。真实浏览器使用本地只读演示数据核对依赖图、审核详情、搜索、状态/阶段组合筛选、空匹配、刷新保持、浅色/深色和 390px 窄屏；未发现浏览器错误，窄屏任务区无横向页面溢出。

本次只改开发仓库，未重启真实服务。正式控制台需要重启加载新增模块资源路由。演示入口：scripts/task-board-preview.cjs。
