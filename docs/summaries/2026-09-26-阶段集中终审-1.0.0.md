# 阶段集中终审 1.0.0 实施记录

已按用户要求移除旧模式兼容，唯一正常工作流为：完整阶段计划 → 逐项执行和小脑初审 → 大脑整体终审 → 追加关联修复任务 → 再次整体验收。

## 交付

- plan 仅登记草案；stage-register 冻结阶段清单后派发。小脑不能改计划，初审通过仅释放阶段内依赖。
- 支持任务依赖和顺序修改相同文件，按执行证据重建整合候选并重跑已配置检查。
- stage-submit 同时核对整体和逐项结论；全部通过才将原任务及累计补修任务 accepted。终审失败保留证据，新任务以 repairKeys 覆盖问题。
- 小脑离线不降级逐项终审。预算、异常唤醒、持久化恢复、只读候选、交接、重置和清理均接入阶段流程。
- 管理台展示阶段与问题；技能、命令说明和运行文档同步更新。版本统一为 1.0.0，服务状态格式为 version 2，拒绝旧版队列。
